# Agent instructions

This repo splits agent guidance by concern:

- For regular app development (architecture, coding conventions, file organisation), see [`Calendr/AGENTS.md`](Calendr/AGENTS.md).
- For writing or reviewing unit tests, see [`CalendrTests/AGENTS.md`](CalendrTests/AGENTS.md).

## Git and pull requests

- Never push commits or reply to threads before the user review all changes.
- Never resolve review threads on pull requests. Reply if asked, but leave threads unresolved.
